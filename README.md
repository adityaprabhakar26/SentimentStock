# SentimentStock
This project is a collection of code used for my independent research project at GW analyzing the relationship between stock price and sentiment, and seeing if we can predict stock price from sentiment from StockTwits

There is a webscraper file(bs4, selenium), a file which uses NLP to analyze sentiment(hugging face roBERTa-base),a few correlation ones back when I was trying linear regression(scipy pandas numpy stuff), and then a few LSTM models I built with keras + sklearn.

The files are pretty messy since this was scrapy work, it was my first experience with actually creating a full project and i didn't have much of a plan. Sorry about the mess, and how the structure is pretty flawed.
